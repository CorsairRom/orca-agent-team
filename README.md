# orca-agent-team

A two-chat agent team for [Orca](https://github.com/stablyai/orca) and Claude Code: an **Ideas** chat that turns
requests into product requirements, and a **Tech-lead** chat that plans, dispatches and reviews the work of
supervised workers across the repositories of one product stack.

This repository is being set up. The full documentation, configuration and bootstrap prompt are on their way.
